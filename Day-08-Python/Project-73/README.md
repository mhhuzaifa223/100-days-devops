# Project 73: Automated File Organizer

## Overview
A Python script that organizes files into folders based on their extensions.

## Features
- Categorizes documents, images, code, and archives
- Creates destination folders automatically
- Skips directories
- Avoids overwriting duplicate filenames
- Reports the number of files moved

## Requirements
- Python 3.8+
- No third-party packages required

## Run
python file_organizer.py

## Test directory
The script operates on the test_files/ directory to avoid modifying unrelated files.

## Learning outcomes
Practiced pathlib, dictionaries, loops, conditionals, file extensions, directory creation, and shutil.move.
