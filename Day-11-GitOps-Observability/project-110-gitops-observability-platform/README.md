# Project 110 — Complete GitOps + Observability Platform

## Goal
Bring GitOps deployment, Kubernetes metrics, centralized logs, and alerting into one local lab.

## Tools
- Kind and Kubernetes
- GitHub
- Argo CD
- Helm
- Prometheus
- Grafana
- Loki and Promtail
- Alertmanager

## GitOps
Argo CD manages applications from Git. Automated synchronization applies changes committed to the repository.

## Observability
- Prometheus collects Kubernetes metrics.
- Grafana visualizes metrics and logs.
- Loki stores and queries container logs.
- Promtail collects container logs.
- Alertmanager routes alerts generated by Prometheus rules.

## Validation
Verify the relevant resources with:
- kubectl get applications -n argocd
- kubectl get pods -n monitoring
- kubectl get prometheusrule -n monitoring
- Grafana Explore for Loki logs
- Prometheus query: up

## Notes
This is a local Kind learning environment. No AWS resources are required. Distributed tracing is not included unless a tracing backend and instrumentation are configured and verified.
