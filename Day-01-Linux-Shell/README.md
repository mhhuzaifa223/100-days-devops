# Day 1 — Linux & Shell Scripting

Day 1 focuses on Linux fundamentals, Bash scripting, system administration,
automation, monitoring, troubleshooting, security, logging, and backup/recovery.

## Projects

| # | Project | Main Concepts |
|---|---|---|
| 01 | Automated System Health Checker | CPU, RAM, Disk, SSH, Uptime |
| 02 | Disk Usage Alerting Script | Disk monitoring, thresholds, alerts |
| 03 | Automated User Management | Users, Groups, Permissions |
| 04 | Linux Server Hardening | UFW, SSH security, least privilege |
| 05 | Automated Backup & Restore | tar, compression, backup/restore |
| 06 | Log Analysis & Error Detection | grep, awk, log analysis |
| 07 | Application Process Watchdog | Processes, PIDs, restart automation |
| 08 | Log Rotation Automation | Log management, compression |
| 09 | Real-Time System Monitor | Monitoring, loops, system metrics |
| 10 | Automated Backup & Restore Solution | Retention, recovery, validation |

## Learning Approach

Each project followed:

**Understand → Build → Break → Troubleshoot → Explain → Interview**

The projects were tested locally on an Ubuntu Linux environment.
